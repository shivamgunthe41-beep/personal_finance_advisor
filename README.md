# Personal Finance Advisor Bot

An AI-powered Personal Finance Advisor Bot that analyzes monthly income and expenses and provides personalized budgeting, spending analysis, and saving suggestions.

## Features

- Monthly income and expense analysis
- Category-wise spending analysis
- Personalized monthly budget
- Recommended savings allocation
- Financial goal-based suggestions
- AI-generated financial insights using Google Gemini
- Structured financial summary
- Responsive web interface
- Flask REST API backend
- Local deployment support

## Technology Stack

### Frontend
- HTML5
- CSS3
- JavaScript
- Fetch API

- Google Fonts - Inter

### Backend
- Python
- Flask

### AI
- Google Gemini API
- Google GenAI Python SDK
